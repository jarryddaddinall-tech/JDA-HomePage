About

Lattice Prop is buy-to-let portfolio software built for how UK landlords actually work — not generic accounting wrapped in a property skin. Whether you own your first rental or manage dozens of postcodes, the same dashboard scales with you.

Add properties with postcode lookup and Land Registry context, track renewals in one place, and model deals against holdings you already own. The live web demo uses HM Land Registry data on Vercel; the iOS app mirrors the same calm CEO-style overview natively.
